# Research playbook

## Where to look
| Source | Good for | How |
|---|---|---|
| Core77 (core77.com) | Design news, Design Awards (Consumer Technology category), long-running discussion boards on parting lines, materials, processes | Search `site:core77.com <product type>`; boards at boards.core77.com |
| Designboom (designboom.com) | Product/tech launches, brand collaborations, tag pages (e.g. /tag/teenage-engineering/) | `site:designboom.com <brand or category>` |
| Lemanoosh (lemanoosh.com) | ID trend digests, CMF, "decoded" teardowns of form language | `site:lemanoosh.com <trend or brand>` |
| Yanko Design | Concepts (treat as inspiration, not production-feasible) | Filter for real products vs renders |
| Brand sites | Official specs, materials, colorways | Use for any material/spec claim |
| Molder / supplier guides (Protolabs, Xometry, Avient, EJOT, Covestro, SABIC, Mold-Tech) | DFM numbers, material data, textures, screws | Cite the guide actually read |
| iFixit teardowns | Real internal architecture, fasteners, part breaks | Great for "how did they build it" |
| Pinterest / Behance / Dribbble | Mood & form exploration | Often not machine-readable — ask the user for screenshots/board exports |

## Process
1. 3–6 searches max for inspiration; prioritize real, shipped products in the category and one adjacent category.
2. For each keeper, note: form move, part-break strategy, CMF, touch-point idea. One line each.
3. Check an iFixit teardown or brand spec page when a claim about construction matters.
4. Pull 2–3 current trend signals (CMF, sustainability, interaction) and state how the design responds or deliberately doesn't.

## Honesty rules
- Link only pages you retrieved in this session. If a fetch failed (paywall, robots, 401), say so and don't describe its content.
- Separate **observed** (from a page), **inferred** (your reading of images/specs), and **proposed** (your design idea).
- Mark any market/stat/trend number as needing verification unless it came from an authoritative, current source.
- Never present a concept render (Yanko/Behance) as a shipped product.
